## Pourquoi ça ne fonctionnait pas ?

### Explication technique

React utilise la **comparaison de références** pour détecter les changements :

javascript

```javascript
// Même référence = Pas de re-render
const obj1 = { a: 1, b: { c: 2 } };
const obj2 = obj1; // Même référence !
console.log(obj1 === obj2); // true → React ne re-render pas

// Nouvelle référence = Re-render
const obj3 = { ...obj1 }; // Nouvelle référence
console.log(obj1 === obj3); // false → React re-render !
```

MongoDB + Socket.IO peuvent renvoyer le **même objet JavaScript** (même référence mémoire) si les données n'ont pas changé structurellement, même si le contenu a changé.

**Solution** : Forcer systématiquement une nouvelle référence avec le spread operator `{ ...document }`.

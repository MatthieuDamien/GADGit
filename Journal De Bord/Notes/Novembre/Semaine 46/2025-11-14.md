## Comment ça fonctionne maintenant

1. **Pendant l'exécution** : Les erreurs/notifications sont préparées et écrites dans le fichier mail (comme avant)
2. **À la fin du cycle** : La méthode `_cleanup()` est automatiquement appelée et exécute le script mail
3. **Les mails sont envoyés** : Toutes les commandes mail accumulées sont exécutées via bash

Maintenant, quand vous exécutez l'autolauncher et qu'une erreur se produit, vous devriez voir dans les logs :

```
INFO - Mails envoyés avec succès (X commande(s))
```

au lieu de juste :

```
ERROR - Mail erreur préparé pour critical/concat
```
